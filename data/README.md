# Data

Raw quantum trajectories are generated by the code and are not committed here.

A baseline trajectory dataframe contains one row per trajectory and time sample, including the reduced observables and jump metadata. The original development run used 200 trajectories and 1001 time samples.

To regenerate the baseline data:

```bash
python scripts/reproduce_full.py
```

Generated files are written under `results/generated/`. If a public archival dataset is deposited later, add its DOI or permanent URL here.
